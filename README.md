## Cloudflare
For a Git-integrated Pages project, use main as the production branch, no framework/build step, and dist as the output directory.
Current Direct Upload projects cannot switch to Git integration in place; retain the existing deployment until a migration is deliberately configured. Repository preparation does not change hosting.
