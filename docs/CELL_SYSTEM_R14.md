# Integrated cell system and previous-system comparison

Studio consumes the R14 canonical System export. The current model uses 900 × 1200 planning cells and a regular support lattice shared by building and terrace. Geometry and comparison quantities are generated in Python, never in Studio JavaScript.

Additional information now compares the selected new and previous configurations: structural footprint, wall assemblies, physical wood parts, geometric wood types and foundation support count. Links open actual model-derived plans for both. The named sizes no longer imply equal footprints; the comparison says so explicitly. No cost, speed or manufacturing-equivalence claims are made.

Existing configuration choice controls, Lithuanian default, white model presentation, disabled PDFs and two website roof options remain. Studio v1 and WikiHouse are preserved. Source pin changes require the System suite and Studio/browser checks; native Rhino acceptance and structural engineering remain separate.
